Rust and npm dependency notices
-------------------------------
Core/CLI and Desktop use Rust dependencies including Clap, Serde, chrono,
csv, rust_decimal, rust_xlsxwriter, TOML, ureq, Tauri and Tauri plugins.
The exact versions and dependency graphs are tracked in Cargo.lock,
apps/desktop/src-tauri/Cargo.lock and apps/desktop/package-lock.json.

The Windows build copies package-supplied copyright, license and notice
files into licenses/rust/ and licenses/npm/ and includes the version-specific
supplemental Rust notices described below. The accompanying
licenses/DEPENDENCIES.txt identifies the collected packages, their declared
license metadata, exact source archive locations where available and the
copied files' directories. The Rust collection follows the Windows x64
normal/build dependency graphs of both Cargo packages; npm collection
uses installed non-dev lock entries plus Vite and Rolldown. This
intentionally conservative collection can include build-only inputs and
is not a complete analysis of the final linked or tree-shaken binaries.
Empty package notice files are omitted and flagged in the index. Supplemental
upstream files are recorded separately in each package's index entry and are
counted alongside package-supplied notices. Check any remaining missing or
empty notice against its upstream source before distribution.
The project uses the locked upstream dependencies; source for registry
packages is available from the exact package archive locations in the index.
This notice is not a substitute for the applicable upstream license terms.

Distribution boundary
---------------------
Microsoft Edge WebView2 Runtime is supplied by the Windows system and is
not bundled. Node.js/npm, Rust tooling, Python Help tooling and frontend
build-only tools such as lightningcss (MPL-2.0 in the npm lockfile) are not
shipped as separate components in the Windows distribution.

External tools such as Meters, Powers, Scopes, Serial and Wavegen are
separate programs and distributions; their own license terms and notices
apply. They are not bundled by Orchestrator Tool. Preserve LICENSE, this
notice and the accompanying licenses directory when distributing the EXEs.
